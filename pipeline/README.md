# Pipeline

Точка входа будущих CLI-инструментов и Blender Python/`bpy` для производства
мультфильмов «Үкі». На этапе M0.1 здесь только документация и пустые каталоги;
исполняемых заглушек и зависимостей нет.

| Каталог | Будущее назначение |
| --- | --- |
| `blender/` | Работа с библиотеками ресурсов, Actions и сборкой сцен через `bpy` |
| `krita/` | Подготовка и экспорт слоёв реальных исходников Krita |
| `render/` | CLI-запуск Blender, рендер и сохранение локальных результатов |
| `../tests/` | Проверки будущих инструментов |

Контекст: [производственный процесс](../docs/production-pipeline.md) и
[правила ресурсов](../docs/assets-guide.md).

При реализации инструмента документировать команду запуска, поддерживаемые
версии приложений, входы, выходы и проверку результата. Ссылаться на общие ресурсы
относительными путями, генерировать результаты в `output/`. Исходники не изменять
автоматически: производные файлы создавать отдельно и фиксировать их происхождение.
Автоматическая перезапись оригиналов не допускается.

Настройка Blender MCP, wing rig, анимация и первый тестовый рендер относятся
к отдельным следующим issues. Лицензия будущего кода утверждается отдельно
от лицензий художественных ресурсов; сейчас ни одна из них не назначена.
