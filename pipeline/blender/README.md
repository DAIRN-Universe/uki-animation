# Blender: единая модель Үкі

[Построение, контроллеры и 16 фаз](../../characters/uki/model/README.md).
[Результат и ограничения](../../characters/uki/model/report-v4.md).

`build_uki.py` запускается внутри Blender 4.0.2. Создаёт один mesh, rig и
отдельную книгу, сохраняет `.blend`, контрольные PNG и короткий тест движения
в новый игнорируемый каталог. Семь исходников сверяются по SHA-256 до работы.
`verify_uki.py` проверяет повторно открытый `.blend`: топологию, длины рёбер,
костей, IK, контрольные контакты, FPS, маркеры и сохранность референсов.
`uki_character.json` задаёт исходные хеши, 16 нумерованных фаз и технический тайминг.
В v3 книга переносится без поворотов и раскрывается крылом на опоре.
`render_opening_study.py` создаёт боковую проверку раскрытия без манипуляции кистью.

В Git нет художественных бинарных файлов. Этот прототип не заменяет отдельную
работу по библиотекам, Actions, постановке сцен и pipeline EP01 (#11).

`avian_body.py` строит птичьи формы v4 и семиперьевой хвост.
`verify_wing_preservation.py` сравнивает крылья с v3;
`make_view_comparison.py` собирает аналитический лист четырёх ракурсов
через FFmpeg, сохраняя оригинальные PNG без изменений.
