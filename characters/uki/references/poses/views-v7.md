# Ракурсы Үкі v7 для Image-to-3D

Подготовлены по [задаче #13](https://github.com/DAIRN-Universe/uki-animation/issues/13)
для эксперимента #12. Четыре основных ракурса — анфас, ¾, профиль и сзади.
Пятый, тело в профиль с головой к зрителю, сохранён отдельно как дополнительный.
Все исходные рисунки приняты автором **Андреем Свининых** в #7.
Экспорты имеют статус `verified_export`: это проверенные производные файлы,
а не новое художественное утверждение или готовая 3D-модель.

## Экспорт

Источник — `uki.poses.v7`, неизменённый `uki_five_views_brush_cleanup_v7.kra`.
SHA-256: `91e1ad07a4e980f903f4af432bdf157332be799b88f028c3597ba262db1c5340`.
Локальная копия проверена Asset Sync перед экспортом. Дата — **27.10.2026**,
приложение — **Krita 6.0.4.1 (git bd6e8d0)**.

Проверены пять верхних групп. Экспортированы проекции каждой группы на полном
исходном холсте **440×560 RGBA/U8**; скрытые группы прочитаны без переключения
их видимости. Из исходного KRA взят и встроен цветовой профиль
`sRGB-elle-V2-srgbtrc.icc`; метаданные разрешения — 120 DPI.

Прозрачный фон и сглаженные края сохранены. Ресайз, обрезка, зеркальное
отражение, выравнивание, правка рисунков и генерация новых деталей не выполнялись.
В общем листе изображения стоят в исходном масштабе; сверху отдельная полоса
подписей высотой 56 px со светлым фоном. Под персонажами фон прозрачный.
Для сервиса с multi-view предпочтительны отдельные PNG без подписей;
общий лист удобен для сверки и сервисов, принимающих один составной референс.
Возможности конкретного сервиса проверяются отдельно в #12.

[Скрипт экспорта](../../../../pipeline/krita/export_reference_views.py)
запускается **внутри Krita 6**, в Python console либо через MCP `run_python`:

```python
import sys
from pathlib import Path
from krita import Krita
repo = Path('/absolute/path/to/uki-animation')
sys.path.insert(0, str(repo))
from pipeline.krita.export_reference_views import export
report = export(Krita.instance().activeDocument(), repo)
```

До запуска открыть проверенный KRA v7. Скрипт требует совпадения хеша,
параметров и пяти групп, а также отсутствия несохранённых изменений.
Существующий каталог экспортов не перезаписывает. Повторная производная
редакция должна иметь отдельный путь/версию; для получения уже проверенной
версии использовать sync, а не повторный экспорт. Неполный результат при
ошибке не считать готовым: сверять отчёт и манифест.
Локальный `export-report.json` фиксирует настройки, группы, alpha bounds,
хеши проекций и PNG; `drive-roundtrip.json` — проверку скачивания с Drive.
Отчёты лежат рядом с локальными PNG и не содержат токенов/временных URL.

## Проверка согласованности

Общий образ, цвета, пропорции головы/корпуса и сложенные крылья читаются
согласованно; расправленных крыльев и дополнительных «рук» нет. Силуэт не
обрезан холстом, лапы входят целиком. Видимые пальцы/когти сохранены из оригинала.
Скрытые ракурсом пальцы по этим рисункам нельзя проверить полностью; это
нужно учитывать при оценке результата 3D, не дорисовывая исходник автоматически.

Рисунки являются художественными референсами, а не точными ортографическими
проекциями. Сохранены естественные различия перспективы, положения глаз,
оперения, ширины силуэта и постановки лап. Измерения области ненулевой альфы:

| Ракурс | Левая/верхняя границы, px | Ширина×высота силуэта, px | Нижняя граница, исключая её |
| --- | --- | --- | --- |
| Анфас | 62 / 23 | 317×527 | 550 |
| ¾ | 66 / 23 | 307×526 | 549 |
| Профиль | 62 / 17 | 316×532 | 549 |
| Сзади | 70 / 20 | 301×524 | 544 |
| Дополнительный | 62 / 19 | 355×530 | 549 |

Разброс высоты четырёх основных силуэтов — **8 px**, нижней границы — **6 px**.
Он уже присутствует в принятых рисунках. Масштаб и положение специально не
нормализованы. Для #12 сравнить модель со всеми четырьмя видами и использовать
пятый как дополнительную проверку головы/тела; не трактовать отличия рисунков
как точные измерения геометрии.

## Фактическая проверка результата

- Все шесть PNG декодируются как RGBA, размеры совпадают с таблицей.
- У отдельных видов углы прозрачны, alpha bounds не выходят за холст.
- SHA-256 распакованных BGRA-пикселей каждого вида совпал с проекцией его группы
  в Krita. Каждый из четырёх участков листа побайтно совпадает с отдельным PNG.
- Встроенный ICC во всех файлах совпадает с ICC исходного KRA; его SHA-256:
  `5991c8d8fcb628dad5d052d9341df8a32bd3c7a794c913a8ede8eae4b34b4545`.
- После загрузки проверены Drive IDs, MIME, размеры и папка назначения;
  файлы скачаны обратно, их байты и SHA-256 совпали с локальными экспортами.
- После экспорта исходный документ остался `modified: false`, видимость групп
  сохранена, SHA-256 KRA до и после совпадает.

Лицензия художественных материалов автоматически не назначается.
