# Отчёт #17: единый прототип Үкі v1

Дата: 27.10.2026. Blender **4.0.2**, Linux. Ветка
`feat/uki-blender-character-model`, основана на актуальном `origin/main`
`6742fcb`. Один mesh совы и один rig используются для всех ракурсов и 16 фаз.
**Результат — технический прототип, не утверждённая художественная модель.**
Машиночитаемая [независимая проверка](validation-v1.json) сохранена в Git.
Критерий удержания — читаемый сгиб и перекрытие книги перьями; плотный
физический зажим по уточнению автора не требуется. Готовность к производству
EP01 не заявляется.

## Метод и исходники

Выбран разрешённый в #17 ручной путь: процедурное моделирование объёмов,
замкнутых перьев, глаз, лицевой маски, синих ушных кисточек и золотых украшений.
Один `UkiMesh` состоит из постоянных островков. Это обоснованно для проверки
механики: можно воспроизвести сетку, контролировать длину перьев и точно
проверять все положения. Результат не выдаётся за нейросетевую генерацию.
Сервис, модель AI, платные параметры, лицензия провайдера: **не применимы**.
Платная генерация не заказывалась. Лицензии художественных исходников и
созданного прототипа автоматически не назначаются; решение остаётся за автором.

Использованы пять утверждённых рисунков v7 и Animation Reference v1.0.
Все семь исходных SHA-256 проверяются до сборки и при независимой проверке.
Ни KRA, ни PNG не редактируются. Пять ракурсов из #13 доступны по прежним
Drive IDs. Новый исходный референс:

- Drive ID: `1ISWQTFLIAiw4RYTCgjxaeHJHxXBd9PPS`.
- SHA-256: `650013e9794c940d88d6129bb2fef3303235c7c8dc933f3593b051e3a3cdc445`.
- Размер: 2 207 472 байта; локальный путь и происхождение — в манифесте.

Исходники сцен 00/04 из #9 не получены. Книга, стопки и подставка сделаны
как простые технические proxy по смыслу утверждённой последовательности,
не как художественная реконструкция отсутствующих сцен.

## Оценка формы и материалов

Рост около 3,1 условной единицы. Голова: эллипсоид с полуосями 0,70/0,49/0,62;
корпус: 0,53/0,43/0,67. Рисунки не являются точными ортографическими чертежами,
поэтому эти размеры — параметры прототипа, а не измеренная анатомия Үкі.

| Контрольный вид | Наблюдение по реальному рендеру |
| --- | --- |
| Анфас | Сохраняются крупная голова, светлое лицо/грудь, большие глаза, синие крылья/кисточки и золотые акценты. Маска разбита на выпуклые объёмы; глаза выступают, оперение и орнамент заметно упрощены. |
| ¾ | Проверяется одна и та же объёмная модель. Голова и корпус читаются, но соединения деталей, посадка маски и декоративные линии требуют художественной переработки. |
| Профиль | Глубина тела/головы и клюв существуют в 3D; глаза и маска слишком выступают. Хвост и контур крыла значительно проще принятого рисунка. |
| Сзади | Есть коричневое многослойное оперение, хвост и синие крылья. Перья выглядят отдельными каплевидными деталями, не воспроизводят живописную фактуру оригинала. |
| Тело в профиль, голова к зрителю | Поворот головы на 90° проверен на том же skeleton; дополнительный mesh головы не создавался. Силуэт маски требует тех же исправлений. |

На каждой лапе три передних пальца и один небольшой задний палец/коготь.
Когтистых рук на крыльях нет. Материалы — 11 простых Principled BSDF,
цвета заданы вручную. Текстуры/живописная поверхность не воссозданы;
референсные PNG упакованы в `.blend` для просмотра, не используются как
выданная за готовую текстуру проекция. Материалы не являются утверждённой
палитрой production-модели. Точная художественная симметрия не заявляется:
базовые объёмы и крылья строятся симметрично, блики глаз ориентированы к камере.

## Skeleton, движение и книга

В варианте без суставных пальцев 17 костей: root/body/head, две лапы, плечо/предплечье/запястье каждого крыла,
три группы перьев на каждую сторону. IK без растяжения. Все фазы используют
один mesh, без подмены геометрии, visibility swaps и shape keys.
Сгибание в плечах/локтях, разворот запястий, веер перьев и поворот корпуса
реализованы; основная геометрия привязана жёсткими островками, а основания двухчастных пальцев имеют смешанные веса.

Книга — отдельная иерархия с двумя шарнирами обложек и статичными блоками
страниц. Перелистывание по уточнению автора не реализуется. Установлены две контрольные точки на обложках.
Траектория книги гладко вычисляется и запекается на каждый кадр; переходы
захвата не используют скачок родительской системы. Это управляемое движение,
не физическая симуляция. Рендеры показывают закрытые/открытые положения,
перенос и возврат крыльев. Стопки и центральная подставка — staging proxy.

181 кадр при 24 FPS; 16 исходных номеров сохранены в timeline markers.
[Таблица всех фаз и инструкции](README.md). Схема тестовых Actions сохранена
в `.blend`; FPS/диапазон не меняют тайминг эпизода.

## Фактические проверки

Независимый `verify_uki.py` запускался после повторного открытия сохранённого
`.blend`, а не только в процессе его построения. Результат: **passed**.

| Проверка | Результат |
| --- | --- |
| Mesh | 18 546 вершин, 20 460 граней, один `UkiMesh` |
| Топология | 0 non-manifold edges, 0 вырожденных граней; островки замкнуты |
| Кости | 23 с двухчастными пальцами; длины постоянны во всех 181 кадрах |
| Геометрия | Количество вершин/граней неизменно во всех 16 фазах |
| Рёбра жёстких деталей | 38 176 рёбер; максимальное изменение длины `4,74×10⁻⁷` единицы |
| IK | Максимальная ошибка `9,16×10⁻⁵` единицы; недосягаемых целей нет |
| Контрольные захваты | Запястье совпадает с маркером на опорных кадрах с активным захватом, допуск 0,001 |
| Путь книги | Максимальный шаг между соседними кадрами 0,0766 единицы; траектория непрерывна |
| Источники | Все семь хешей совпадают, исходники не изменены |

Замкнутые островки не означают единую непрерывную кожу или отсутствие
взаимных пересечений. Рендеры показывают намеренные перекрытия оперения;
заметные пересечения оцениваются визуально. Формальная проверка mesh
не заменяет авторскую оценку силуэта и перекрытий.

## Решение о пригодности

**Для следующей итерации rig — пригоден как воспроизводимая основа механики.
Для производственной анимации — пока не пригоден.**

Для дальнейшего производства нужны: уточнение силуэтов/лицевой маски/глаз/клюва, живописное оперение и
орнамент; уточнение геометрии крыла, моргание/мимика. При повороте корпуса связь с лапами
и переходы плеча пока выглядят жёстко. Перелистывание исключено из scope по последующему указанию автора. Фаза 08 использует временную
подставку, а не симуляцию опоры на стол. Все эти ограничения остаются открыты.

По дополнительному запросу автора выполнен
[анализ двухчастных пальцев](finger-phalanges-analysis.md): рекомендованы
три цепочки по две части внутри перьевого силуэта, с изменением геометрии
суставов и проверкой кончиков. По последующему уточнению автора реализован вариант `--articulated-fingers`: 23 кости,
две части каждого пальца, гибкие основания и жёсткие наружные перья. Проверка всех 181 кадров проходит;
A/B-крупный план демонстрирует сгибание тех же пальцев. Оценивается видимый сгиб и перекрытие книги перьями. Плотное прилегание
кончиков и физическая симуляция зажима не являются требованиями автора.

`.local-assets/characters/uki/model/v1-review/`.

- `front.png`, `three_quarter.png`, `profile.png`, `back.png`, `profile_head_front.png` — пять видов.

  `finger_curl.mp4` и `finger-study.json`.

Флаг `--articulated-fingers` добавляет двухчастные пальцы к тому же персонажу.
Внутри последовательности геометрия не меняется. Остальные локальные каталоги
предыдущих проверок — промежуточные, не итоговые артефакты.

[Папка результатов Drive](https://drive.google.com/drive/folders/1TYtUy-KK1I-0SYWiG5wjoe1upPGM8Jpr)
создана внутри существующей `uki-animation-assets/characters/uki/`.
**Загрузка итоговых файлов заблокирована автоматической проверкой разрешений**:
две попытки отклонены как передача в неподтверждённую папку. Явное разрешение
автора на эту папку запрошено. Папка не означает, что артефакты загружены;
Drive IDs для результатов не выдумываются и не добавляются в Asset Sync.
После разрешения: загрузить, скачать обратно, сверить байты/хеши, затем
зарегистрировать реальные IDs в манифесте. До этого PR остаётся draft,
#17/#12/#16 не закрываются.

В Git коммитятся только код, JSON-конфигурация, Markdown и манифест исходного
референса. Никакие `.blend`, PNG, видео, архивы и credentials в Git не добавляются.
