# Единая модель Үкі — v1, проверочный прототип

Работа по [#17](https://github.com/DAIRN-Universe/uki-animation/issues/17):
**#13 → #12 → #16**, одна ветка `feat/uki-blender-character-model` и один PR.
Это первая вручную построенная процедурная 3D-интерпретация, а не утверждённая
художественная модель или готовый материал EP01. Сопоставление и ограничения —
в [отчёте](report-v1.md).

## Источники

- Неизменённый KRA v7 и [пять экспортов #13](../references/poses/views-v7.md).
  Повторный экспорт не нужен: #13 закрыта и уже включена в `main`.
- Неизменённый [Animation Reference v1.0, 16 кадров](https://drive.google.com/file/d/1ISWQTFLIAiw4RYTCgjxaeHJHxXBd9PPS/view?usp=drivesdk).
  Запись `uki.animation-reference.v1` в [манифесте](../../../assets/manifest.yaml).
- Исходники сцен 00/04 по #9 не зарегистрированы; в этой работе нет реконструкции
  их художественных оригиналов. Книга и стопки — технические объекты для проверки
  механики, не принятый дизайн реквизита.

## Построение и проверка

Для варианта с двухчастными пальцами добавить `--articulated-fingers`
и выбрать отдельный новый каталог, например `v1-review`. Внутри каждой
сборки используется один неизменный mesh на всех фазах.

Нужны Blender **4.0.2**, Python для Asset Sync и FFmpeg (для проверки видео).
Запускать из корня репозитория. У Blender собственный Python, `bpy` через pip
устанавливать не требуется.

```bash
.venv/bin/python -m pipeline.assets sync --character uki --credentials .secrets/drive-user.json
.venv/bin/python -m pipeline.assets verify --character uki
blender -b --factory-startup -t 4 --python-exit-code 1 --python pipeline/blender/build_uki.py -- \
  --output .local-assets/characters/uki/model/v1-review --articulated-fingers --render --animate
blender -b .local-assets/characters/uki/model/v1-review/uki_character_v1.blend \
  -t 4 --python pipeline/blender/verify_uki.py -- --report output/uki-validation.json
```

Выходной каталог должен быть новым, внутри `.local-assets/` или `output/`.
Существующий результат не перезаписывается. Проверять не только exit code Blender:
при Python-ошибках Blender может вернуть 0. Требуются `UKI VALIDATION` в логе
и JSON со `status: passed`; в автоматизации добавлять `--python-exit-code 1`.
Скрипт сверяет семь исходных хешей до построения. Повторная версия использует
новый каталог; после переноса клона `.blend` работает со встроенными PNG,
пути изображений относительные. KRA не встраивается и не изменяется.

Настройки размеров и 16 фаз находятся в
[`uki_character.json`](../../../pipeline/blender/uki_character.json).
Исполнитель — [`build_uki.py`](../../../pipeline/blender/build_uki.py),
независимая проверка сохранённого файла —
[`verify_uki.py`](../../../pipeline/blender/verify_uki.py).
Время проверки — **181 кадр, 24 FPS, 7,54 с**; это технический тест, не тайминг EP01.
Контрольные изображения — EEVEE, 640×640; движение — Workbench, 640×480, H.264, 8 FPS (каждый третий кадр
24-FPS сцены, с сохранением темпа). Крупный план пальцев — 24 FPS.

## Использование rig

- `UkiMesh` — единственный mesh совы; голова, корпус, лапы и перья — его
  постоянные островки. `UkiRig` — 17 костей (23 с двухчастными пальцами) и один Armature modifier.
- `root` — общий перенос, `body` — корпус, `head` — голова,
  `foot.L/R` — лапы. Поворот головы вокруг вертикали — локальная ось Y кости.
- `CTRL_wrist.L/R` — мировые IK-цели. Двухзвенная цепь `upper → forearm`
  не растягивается; `wrist` копирует ориентацию контроллера.
- `feathers1/2/3.L/R` — три управляемые группы перьев на каждое крыло,
  без когтистых рук. Перья жёстко взвешены; у варианта с фалангами добавлены гибкие
  основания с весами соседних суставов и кости `feathersN_tip.L/R`.
- `BookRoot` — отдельная иерархия книги; `CoverHinge.L/R` — обложки,
  `Grip.L/R` — контрольные точки захвата.
  Книга движется по явно записанной траектории, без динамической симуляции.
- На объектах Actions `Uki_BookStudy_*`; timeline markers сохраняют исходные
  номера и английские подписи листа. Для своих действий дублировать Action,
  отключать тестовые Actions целей/книги согласованно. Это пока полная тестовая
  сцена; готовая система библиотек/Library Overrides по #11 не реализуется.

L/R здесь обозначают стороны **экранного анфаса** (L — слева на рисунке),
а не анатомическую номенклатуру. Одна единица Blender — условная единица
прототипа, рост около 3,1; физический размер персонажа автором не задан.

## Нумерация Animation Reference v1.0

Последующее указание автора имеет приоритет над исходным заданием:
**проверять удержание книги двухчастными пальцами, без перелистывания;
плотный зажим не требуется, контакт скрывают перекрывающие книгу перья**.
Номер 10 и исходная подпись сохранены в таблице для сопоставления;
в тестовой анимации это удержание, а не поворот страницы.

Промежуток между опорными состояниями — 12 кадров. Координаты книги и корпуса
в конфигурации — постановочное решение прототипа; в 2D-лист они не вносятся.

| № / кадр | Исходная подпись | Действие, крылья и книга |
| --- | --- | --- |
| 01 / 1 | LOOK LEFT | Взгляд влево; книга лежит на левой стопке, крылья сложены. |
| 02 / 13 | REACH | Корпус поворачивается влево, левое крыло достигает книги. |
| 03 / 25 | GRAB BOOK | Двусторонний захват, книга приподнята и наклонена. |
| 04 / 37 | LIFT BOOK | Подъём закрытой книги; оба крыла удерживают её. |
| 05 / 49 | BRING TO CENTER | Закрытая книга перед корпусом, обе точки захвата активны. |
| 06 / 61 | UNFOLD WRIST | Разворот запястий, начинается раскрытие обложек. |
| 07 / 73 | OPEN BOOK | Обложки раскрыты; обе стороны книги поддерживаются. |
| 08 / 85 | SPREAD WINGS | Книга на центральной подставке, крылья раскрываются и освобождают захват. |
| 09 / 97 | READ | Книга снова удерживается перед корпусом. |
| 10 / 109 | TURN PAGE | Оба крыла продолжают удерживать книгу; перелистывание исключено по уточнению автора. |
| 11 / 121 | CLOSE BOOK | Обе стороны захвачены, обложки закрываются. |
| 12 / 133 | MOVE RIGHT | Перенос вправо с поворотом корпуса, книга удерживается. |
| 13 / 145 | PLACE ON RIGHT | Книга положена на правую стопку; правое крыло завершает контакт. |
| 14 / 157 | FOLD WINGS | Захват отпущен, оба крыла возвращаются к корпусу. |
| 15 / 169 | CHECK RIGHT | Взгляд направо; книга неподвижна на правой стопке. |
| 16 / 181 | DONE | Возврат головы, сложенные крылья, книга остаётся справа. |

Исходный лист показывает больше художественной пластики, чем этот rig:
моргание/закрывание глаз, мимика, деформация контура и подробный контакт
перьев со страницей пока не воспроизводятся. Их готовность не заявляется.

[Двухчастные пальцы и A/B-проверка зажима](finger-phalanges-analysis.md)
реализованы по уточнению автора как включаемый вариант `--articulated-fingers`.
Перелистывание исключено из текущей проверки; исходный лист не изменялся.
