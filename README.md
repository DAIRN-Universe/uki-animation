# Үкі — uki-animation

Производственный проект мультфильмов «Үкі»: графика и раскадровка создаются
в Krita, а rig, действия, сцены и рендер — в Blender. Основные персонажи:
Үкі (сова, `uki`) и Кірпі (ёж, `kirpi`). Структура допускает добавление
других персонажей, предметов и эпизодов.

Первое производственное применение — эпизод `ep01`, сцена `sc01`
«взять книгу — положить книгу». Нумерация сцен может уточняться после
импорта реальной раскадровки.

## Состояние M0.1

Подготовлены каталоги и правила работы. Оригиналы раскадровки будут добавлены
отдельно. Наличие каталога не означает наличия готового ресурса: изображения,
модели, звуки, rig и сцены пока не добавлены. Настройка Blender MCP,
построение wing rig и первый тестовый рендер относятся к следующим issues.

## Рабочая среда

- Linux, IntelliJ IDEA с Codex и Git — работа с репозиторием и документацией.
- Krita — исходные `.kra` и экспорт PNG.
- Blender — `.blend`, Actions и будущие инструменты Python/`bpy` и CLI.
- Монтаж — сборка отрендеренных кадров и звука в выбранном редакторе.

Конкретные версии Krita и Blender следует записывать при добавлении материалов.
На этапе M0.1 установка Python-зависимостей и запуск скриптов не требуются.
Репозиторий можно открыть в IDEA через **File → Open**; локальные настройки
IDE не включаются в Git.

| `characters/<id>/textures/` | Намеренно сохраняемые экспорты слоёв в PNG |

| `episodes/ep01/storyboard/originals/` | Неизменяемые оригиналы раскадровки |
| `episodes/ep01/storyboard/selected-frames/` | Отобранные кадры с указанием оригинала |
| `episodes/ep01/scenes/sc01/` | Файлы сцены, использующие общие ресурсы |
| `episodes/ep01/audio/` | Реальные исходные и утверждённые звуковые материалы |
| `episodes/ep01/edit/` | Проект монтажа и решения по сборке эпизода |
| `pipeline/` | Документация и место для будущих CLI/`bpy` инструментов |

Пустые каталоги закреплены файлами `.gitkeep`. В `output/` отслеживается только
такой маркер; всё создаваемое содержимое этой папки игнорируется Git.

## Добавление материалов

1. Прочитать [правила ресурсов](docs/assets-guide.md) и
   [производственный процесс](docs/production-pipeline.md).
2. Добавить существующие оригиналы раскадровки в
   `episodes/ep01/storyboard/originals/`, сохранив их содержимое и происхождение.
   Не заменять их сгенерированными материалами.
3. Отобрать реальные кадры сцены с книгой в `selected-frames/` и записать связь
   каждого кадра с оригиналом. Подтвердить номера сцен и параметры кадров.
4. Разместить общие материалы персонажей в `characters/`, предметов — в `props/`.
   Указать автора, источник, версию, параметры экспорта и статус прав в локальном
   `README.md` рядом с материалами.
5. В сценах ссылаться на общие ресурсы по относительным путям, не дублировать
   их в папках сцен. Работы по rig и анимации вести в следующих задачах.
6. Перед коммитом проверить `git status` и список добавляемых файлов: исходные
   `.kra`, PNG и `.blend` сохраняются намеренно, временные результаты — в `output/`.

Исходники не изменяются автоматически. Исправления оригиналов, переименование
и перезапись требуют отдельного явного решения; производные материалы хранятся
отдельно с указанием источника.

## Лицензии

Лицензии на код и художественные ресурсы определяются раздельно и требуют
отдельного утверждения правообладателями. На этапе M0.1 лицензия ни одной из
этих категорий не назначена. Публикация в репозитории сама по себе не является
разрешением на повторное использование. Сведения об авторах, источниках и
подтверждённых условиях использования записываются при добавлении ресурсов.
