# Правила хранения ресурсов

## Хранилище

**Google Drive — единственное хранилище бинарных художественных материалов.**
KRA, исходные и сгенерированные PNG/JPG, PSD, кисти, Blender-файлы, звук,
видео и архивы не коммитятся в GitHub, включая Git LFS. Это относится также
к превью README. Публичные изображения — только проверенные ссылки Drive
с авторским разрешением; иначе текст. Sharing автоматически не менять.

В Git — Markdown, код, конфигурации и [манифест](../assets/manifest.yaml).
[Asset Sync](../assets/README.md) загружает ресурсы в `.local-assets/`.
Результаты — `output/`, credentials/token — `.secrets/`; всё это игнорируется.
Каталоги `characters/`, `props/`, `episodes/` — документация и логическая
структура. Пустые каталоги с `.gitkeep` от первоначальной структуры не означают
наличия ресурса и не являются целями загрузки. Не создавать новые папки Git
для скачиваемой графики. Не удалять ранее сохранённые оригиналы без проверки
сохранности на Drive. При текущем переходе отслеживаемых бинарных ассетов
в проекте не было.

## Различия материалов и размещение

| Материал | Назначение и локальное размещение |
| --- | --- |
| Исходный KRA | Авторская структура слоёв; `.local-assets/characters/uki/poses/uki_five_views_brush_cleanup_v7.kra` |
| Первичная генерация PNG | Исходный результат генерации, рабочий вариант до авторской проверки; `.local-assets/episodes/ep01/sc00/generated-frames/` |
| Производный экспорт PNG | Слои для Blender с ID/версией исходного KRA и настройками; `.local-assets/characters/uki/exports/<version>/` |
| Художественный storyboard | KRA и выбранные кадры, связанные с текстовыми планами; `.local-assets/episodes/ep01/storyboard/` |
| Rig / Actions | Общие `.blend` библиотеки; `.local-assets/characters/<id>/{rigs,actions}/` |
| Предметы | Общие исходники; `.local-assets/props/<id>/` |
| Сцена | `.blend` с относительными ссылками на общие ресурсы; `.local-assets/episodes/ep01/scXX/` |
| Звук / монтаж | Реальные материалы и проекты; `.local-assets/episodes/ep01/{audio,edit}/` |
| Результаты | Рендеры/превью/кеши; `output/ep01/scXX/<version>/` |

Из перечисленного уже зарегистрирован и проверен KRA v7; остальные пути —
соглашения, не свидетельство наличия файлов. Генерации не подменяют оригиналы
и не считаются готовой анимацией. Производные экспорты создавать локально,
отдельно от исходников; не отправлять в GitHub. Для переноса между машинами
сохранить на Drive и зарегистрировать в манифесте.

## Имена и версии

Оригинальные имена сохранять. Новые файлы: латиница, цифры и подчёркивания,
`<id>_<role>_vNNN.<ext>`. В манифесте записывать версию, исходное имя, реальный
Drive ID, SHA-256 фактических байтов, размер, назначение и статус. Не выдумывать
ID и хеши. `sha256: null` блокирует загрузку; неполные примеры — в документации.

Новая редакция получает отдельные ID, версию и путь после проверки, принятый
оригинал сохраняется. Загрузчик не заменяет локальные изменения и не меняет
версии незаметно. При несовпадении хеша выяснить причину и сохранить рабочую
копию до любого ручного переноса. Общие ресурсы не дублируются по сценам;
теги эпизода/персонажа задают использование, а не копии файлов.

Персонажи: `uki` — Үкі, `kirpi` — Кірпі. Предметы: `book`, `bow`, `arrow`, `lamp`.

## Кадры и параметры

EP01: **00–15**, всего 16 планов. 00 — взять/раскрыть книгу, 01 — чтение,
04 — закрыть/положить. Порядок разработки не задаёт нумерацию; первой для
технической разработки выбрана 04. [Пять принятых поз Үкі](../characters/uki/references/poses/README.md)
относятся к общей пластике персонажа, а не к пяти сюжетным сценам.

Storyboard: **1920×1080, 16:9**. Рабочий аниматик исходных **01–15 — 36 секунд,
24 FPS**. Длительность 00 и новый общий хронометраж — `TBD`; не выводить тайминг
планов из общей суммы. Холст референсов 440×560 не задаёт размер финального видео.

До экспорта записать разрешение, FPS и включённые начало/конец диапазона.
Для PNG — профиль, альфа-канал, исходный слой KRA, холст, обрезку и смещение.
Части персонажа экспортировать с согласованными точками привязки. Не менять
масштаб, профиль и FPS автоматически; различать номер исходной страницы/слоя
и номер кадра анимации.

## Происхождение и права

Документировать автора/правообладателя, источник, имя, дату проверки, версию
Krita/Blender, параметры и статус; для производного файла — ID/версию источника.
Исходники автоматически не изменять. Доступность на Drive не означает
разрешения повторного использования. Лицензии кода и художественных материалов
утверждаются раздельно; CC0/MIT/CC BY-NC-SA автоматически не назначать.
Имеющиеся сведения о происхождении и лицензиях импортируемых кистей сохранять.

Авторский [Markdown storyboard](../episodes/ep01/storyboard/uki_kirpi_storyboard_v1.md)
остаётся в Git без изменений. [README storyboard](../episodes/ep01/storyboard/README.md)
перечисляет зависимости; [реестр](../episodes/ep01/scenes.md) задаёт сцены.
Отсутствующие художественные материалы и ссылки догадками не восстанавливать.
