# Сцена 00 — Үкі берёт книгу

**Статус:** отдельное авторское дополнение к EP01 по
[Issue #5](https://github.com/DAIRN-Universe/uki-animation/issues/5),
предложенное Андреем Свининых 27.10.2026. Это вступление перед исходным
кадром 01, а не изменение [оригинальной раскадровки](uki_kirpi_storyboard_v1.md).
Оригинал по-прежнему содержит ровно 15 кадров **01–15**; вместе со сценой
**00** последовательность эпизода содержит **16 планов, 00–15**.

## Первый набор действий для wing rig

Сцены **00 → 01 → 04** связывают будущие повторно используемые действия:

| Сцена | Действие | Связь |
| --- | --- | --- |
| 00 | take / open — взять и раскрыть книгу | Подготовить положение для чтения |
| 01 | read — читать, удерживая книгу двумя крыльями | Начальное состояние книги из 00 |
| 04 | close / place — закрыть и положить книгу справа | Освободить крылья, лапы остаются на ветке |

**04** — первая выбранная сцена для технической разработки wing rig.
Это порядок разработки; сюжетный порядок остаётся **00–15**.
Rig, Actions, анимация и рендер здесь не реализуются.
